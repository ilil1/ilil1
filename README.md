
#  Ai Software Engineer

4년 차 소프트웨어 엔지니어로서 Full-Stack Ai Service를 구축하는 개발 경험을 쌓았습니다.  
회사의 Native App 과 Flutter 모바일 서비스의 개발·배포를 담당하고, 풀스택 개발 및 Ai Agent 구현 업무를 했습니다.  
회사의 Native App → Flutter 로 초기 설계부터 마이그레이션을 했습니다.  
데이터 특성에 맞는 DB 선정·스키마 설계, 확장 가능한 어플리케이션 아키텍처 설계 역량을 갖추고 있습니다.  
생성형 AI 시대에 기술적 트렌드에 유연한 적응을 하며, ML·DL·Cloud Infra 로 개발 역량을 넓히고 있습니다.  
최근에는 개인 프로젝트를 통해 MLOps와 LLMOps를 학습하며 끊임없이 성장하고, Ai 서비스의 배포·운영 Infra를 구축하고 있습니다.  

또한 개발자로써 기술적 역할에만 국한하지 않으며 제품의 문제를 해결하는 팀원으로써 가능한 모든 부분에 적극적으로 참여합니다.  
Ai 를 통해 다양한 직군의 팀원을 보조할 수 있는 역량을 발휘하여, 제품 전체의 이해 및 다각적인 소통을 지향합니다.
