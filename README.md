
#  Ai Engineer

4년 차 소프트웨어 엔지니어로서 Ai Agent 설계·구현부터 LLMOps 까지 AI 서비스의 전체 라이프사이클 시스템을 구축했습니다.  
LLMOps 의 Evals로 LLM의 응답 품질 평가, Observability 로써 Tracing 및 Monitoring을 하여 안정적인 AI 서비스 운영 시스템을 구현했습니다.  
LLM 서비스와 더불어 ML·DL 알고리즘과 모델 학습 원리를 익히고, LoRA 기반 파인튜닝을 개인 프로젝트로 Ai 에 대한 개발 역량을 넓히고 있습니다.  
데이터 특성에 맞는 DB 선정·스키마 설계, 확장 가능한 어플리케이션 아키텍처 설계 역량을 갖추고 있습니다.  
서비스를 AWS EKS 기반 Kubernetes 환경에 배포하고, Helm·Argo CD를 활용한 GitOps 배포 자동화를 초기부터 구축한 경험이 있습니다.  
회사의 네이티브와 Flutter 앱 서비스의 개발·배포를 담당하고, 기존 네이티브 앱의 Flutter 전환을 초기 설계부터 마이그레이션까지 수행했습니다.  
최근에는 개인 프로젝트에서 MLOps를 학습하며 AI 서비스의 배포·운영 인프라를 구축하고 있습니다.   
또한 개발자로써 기술적 역할에만 국한하지 않으며 제품의 문제를 해결하는 팀원으로써 가능한 모든 부분에 적극적으로 참여합니다.
