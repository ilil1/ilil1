# GovBiz 고도화 프로젝트 기술 보고서

노션 기술 보고서의 본문·표·이미지를 담은 정적 HTML 페이지입니다.

- index.html: 목차, 본문, 설정표, 2열 기능 화면
- styles.css / notion-content.css / script.js: 반응형 레이아웃, 노션 본문 간격과 이미지 확대 보기
- assets/: 노션 본문 이미지와 기술 보고서 PDF (노션 로그인·임시 링크에 의존하지 않음)

별도 빌드 없이 index.html을 브라우저에서 열 수 있습니다. 작은 화면에서는 기능 화면을 한 열로 표시합니다.
